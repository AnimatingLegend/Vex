# Vex.js

### Vector Element Xpansion

A lightweight 2D game engine for JavaScript. Vex gives you a fixed-timestep
game loop, physics-driven sprites, groups with object pooling, a camera
system with follow/flash/fade, frame-based animation, and a tween manager —
all as plain ES modules with no build step required.

## Install / Run the demo

```bash
npm run test
# open the printed localhost URL
```

Arrow keys move, Space jumps. `test/PlayState.js` is a minimal example
showing gravity, platform collision, camera follow, a screen flash, and a
fade-in on load.
